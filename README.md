# 🌐 Personal Web-Portfolio

Современное адаптивное веб-портфолио, созданное для демонстрации навыков фронтенд-разработки. Проект выполнен в минималистичном стиле с акцентом на чистый код и удобную навигацию.

---

## 📁 Структура проекта

Проект реализован с четким разделением логики, стилей и контента:

* **`index.html`** — Главная страница: краткая информация, технологический стек и навигация.
* **`projects.html`** — Каталог работ: интерактивная сетка с карточками проектов и ссылками.
* **`details.html`** — Страница кейса: подробное описание конкретных задач и решений.
* **`style.css`** — Оформление: использование **Flexbox** для адаптивности и кастомных стилей для темной темы.
* **`scripts.js`** — Интерактивность: логика переключения тем (Dark/Light mode) и анимация появления контента.

---

## 🛠 Функционал

Сайт включает в себя ключевые возможности современного веб-интерфейса:

1.  **Dynamic Theme**: Переключение между светлой и темной темами через `classList.toggle` с изменением текста кнопки.
2.  **Responsive Layout**: Адаптивная верстка, которая корректно отображается на ПК, планшетах и смартфонах.
3.  **Smooth Transitions**: Плавное проявление контента при загрузке страницы с использованием CSS `transition` и JS `setTimeout`.
4.  **GitHub Integration**: Прямая ссылка на основной профиль разработчика для ознакомления с исходным кодом проектов.
5.  **Event Handling**: Обработка пользовательских событий и предотвращение стандартного поведения ссылок-заглушек.

## 🚀 Как запустить проект

1.  Склонируйте репозиторий:
    ```bash
    git clone [https://github.com/pokimon2178-star/My-first-cite.git](https://github.com/pokimon2178-star/My-first-cite.git)
    ```
2.  Перейдите в папку проекта:
    ```bash
    cd My-first-cite
    ```
3.  Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Edge).
